# Content formats — playbook shelf

Reusable post formats for Suor Society. Each doc is one format and follows the
same shape: what it is, why it's ours (not a copy), the rule that keeps it on
brand, a vetted bank of lines or examples, the visual, the caption, and the
tone guardrails.

Pull the relevant doc before writing a set. Voice comes from the `about-me`
skill, writing rules from `anti-ai-writing`, strategy from
`hybrid-running-business`.

## The formats

- [`its-weird-that.md`](./its-weird-that.md) — the "it's weird that" carousel
  series. Dry, relatable, easy to read. Early-phase reach format.

## Adding a new one

Copy [`_template.md`](./_template.md), fill it in, and add a line to the list
above. Keep the same section order so every format reads the same way.
