# Canva Template Prompt Pack

## How to use these

Open a new Claude chat with Canva connected. Copy and paste whichever prompt you need. Each one is built to match the Suor Society aesthetic guide (the "Streets to Start Lines" palette, typography, and vibe). Swap in your own placeholder text or real content before generating.

You can also paste multiple prompts in one session and ask Claude to generate them back to back.

---

## 1. Bold Culture Post (Hot Take / Opinion)

This is your "THINGS THAT REQUIRE ZERO TALENT" and "HAPPENED THIS MONTH" style post. Bold text, dark background, scroll-stopping energy.

```
Create an Instagram post (1080x1350) for Suor Society — a hybrid running culture page based in San Diego (@suorsociety).

Design direction:
- Dark background using #141414 (near black)
- Bold uppercase headline text in a condensed display font similar to Archivo Black or Anton
- Text color: #E08855 (burnt orange) or #ECE4D4 (warm bone/cream)
- Subtle grain or noise texture over the background
- High contrast, editorial, magazine-cover energy
- Urban, gritty, raw. Not polished fitness influencer style
- Minimal layout. The text IS the design. No stock photos, no clip art, no icons

Headline text: "RUNNERS WHO LIFT DON'T GET ENOUGH CREDIT"
Subtext (smaller, underneath): "You squatted heavy yesterday and ran 6 today. That's insane."

The vibe is: runneralerts meets a zine. Confident, opinionated, not motivational poster energy. Think streetwear brand meets running culture editorial.
```

## 2. Editorial Carousel Cover Slide

This is the "YOUR NEXT LIFT AND RUN SPLIT" and "3 TIPS to avoid Running Burnout" format. The first slide of a swipeable carousel that stops the scroll.

```
Create an Instagram post (1080x1350) that works as a carousel cover slide for Suor Society — a hybrid running culture page (@suorsociety).

Design direction:
- Background: #2D3340 (dark slate) or #141414 (asphalt black)
- Headline in bold condensed uppercase font (Archivo Black or Anton style)
- Accent color for one word or line: #E08855 (burnt orange) or #EBC34A (highlight yellow)
- Include a small "SWIPE" indicator with an arrow at the bottom right
- Add subtle grain texture
- Clean layout with strong hierarchy. Headline dominates. Subtext is secondary
- No photos on this slide. Pure typography and color

Headline: "5 MOVES THAT MAKE YOUR LONG RUN HURT LESS"
Subtext: "Performance tips for runners who lift"
Small tag at top or bottom: "TRAINING" or the brand tagline area

The feel is editorial and bold. Like the cover of a running magazine redesigned as an Instagram carousel. Not a Canva template with generic shapes and gradients.
```

## Tips for getting better results

- If the first generation looks too generic or "Canva template-y," tell Claude: "Make it grittier. More grain, more contrast, less polished. Think zine, not corporate."
- Ask for 2 to 3 variations so you can pick the strongest one.
- Once you find a template you like, ask Claude to create versions for different content (swap the headline, keep the layout).
- You can also say "use this as the base but make one in the warm cream palette instead of dark" to get both moods.
- If Canva defaults to bright, clean fitness aesthetics, push back: "Darker. More urban. Less wellness, more streetwear."
